Cómo copiarlo sin que rebote

      
    
        
  • Copiá la URL entera desde la barra de direcciones, mientras el usuario está en la pantalla del error.
    • 
        
  • No lo transcribas de una captura. El 0 y la O, el 1 y la l se confunden, y el ID queda mal sin que se note.
    • 
        
  • El ID tiene tres partes. Si mandás solo el token de 12 caracteres, BM no encuentra nada.
    • 
        
  • En modificar, el flujo va siempre como update_omni, con guion bajo. Si viene como updateomni o update-omni, el equipo de bugs lo rechaza. La app lo corrige sola.
    • 
        
  • El número entre paréntesis del mensaje de error es el cause id, va aparte.
    • 
        
  • Si el usuario reproduce el error más tarde, se genera una sesión nueva. Sirve la del momento del error.
    •
